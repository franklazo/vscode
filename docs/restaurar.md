# Restaurar

- (Opcional) Datos sincronizados: *Manage → Settings Sync → Turn Off*
- (Opcional) Desinstalar **VS Code** antes de borrar
- Borrar carpeta `Code` (datos de usuario)
- Borrar carpeta `.vscode` (extensiones)

```text
%APPDATA%\Code

%USERPROFILE%\.vscode
```

- Borrar sólo configuración: *Preferences: Open User Settings (JSON)*
