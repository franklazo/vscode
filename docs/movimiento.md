# Movimiento

- `Clic` → Mover cursor de texto

Movimientos fundamentales:

- `↓`, `↑` → Por línea
- `→`, `←` → Por carácter
- `Ctrl + →`, `Ctrl + ←` → Por palabra

Movimientos complementarios:

- `Fin` → Al final de línea
- `Inicio` → Al inicio de línea
- `Ctrl + Fin` → Al final del texto
- `Ctrl + Inicio` → Al inicio del texto
