# Interfaz

- `Ctrl + Ñ` → Mostrar/ocultar terminal
- `Ctrl + B` → Expandir/contraer barra lateral
- `Ctrl + Shift + P` → Mostrar paleta de comandos

Navegación:

- `Alt + ←` → Ir hacia atrás
- `Alt + →` → Ir hacia adelante
- `Ctrl + Tab` → Ir a archivo abierto
- `Ctrl + Clic` → Abrir enlace en el editor
- `Ctrl + Shift + T` → Reabrir archivos previos

Modo Zen:

- `Ctrl + K` `Z` → Cambiar a modo Zen
- `Esc` `Esc` → Salir del modo Zen
