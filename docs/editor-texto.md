# Editor de texto

- `Insert` → Activar/desactivar sobrescritura
- `Alt + Z` → Activar/desactivar ajuste de línea
- `Ctrl + ↓`, `Ctrl + ↑` → Desplazar vista por línea

En edición de código:

- `F2` → Renombrar símbolo
- `Tab` → Autocompletar sugerencia
- `Ctrl + Espacio` → Mostrar sugerencias de autocompletado
