# Edición

- `Clic sostenido` → Mover selección
- `Ctrl + Clic sostenido` → Copiar selección

Acciones generales:

- `Ctrl + Z` → Deshacer acción
- `Ctrl + Y` → Rehacer acción

Edición general:

- `Ctrl + C` → Copiar selección
- `Ctrl + X` → Cortar selección
- `Ctrl + V` → Pegar selección
- `Backspace`, `Supr` → Borrar selección

Edición de líneas:

- `Ctrl + Shift + K` → Borrar líneas
- `Alt + ↓`, `Alt + ↑` → Mover hacia abajo/arriba
- `Shift + Alt + ↓`, `Shift + Alt + ↑` → Copiar hacia abajo/arriba
