# Multicursor

- `Alt + Clic` → Insertar/borrar cursor de texto

Creación de cursores múltiples:

- `Ctrl + Alt + ↓` → Insertar en línea inferior
- `Ctrl + Alt + ↑` → Insertar en línea superior

Edición de cursores múltiples:

- `Esc` → Borrar todos los cursores
- `Ctrl + U` → Deshacer última operación
