# Selección

- `Shift + Clic` → Expandir/contraer selección

Selección fundamental:

- `Shift + ↓`, `Shift + ↑` → Expandir/contraer por línea
- `Shift + →`, `Shift + ←` → Expandir/contraer por carácter
- `Ctrl + Shift + →`, `Ctrl + Shift + ←` → Expandir/contraer por palabra

Selección complementaria:

- `Shift + Fin` → Expandir/contraer al final de línea
- `Shift + Inicio` → Expandir/contraer al inicio de línea
- `Ctrl + Shift + Fin` → Expandir/contraer al final del texto
- `Ctrl + Shift + Inicio` → Expandir/contraer al inicio del texto

Selección extra ratón:

- `Clic` `x2` → Seleccionar palabra
- `Clic` `x3` → Seleccionar línea
- `Clic` `x4` → Seleccionar todo

Selección extra teclado:

- `Ctrl + A` → Seleccionar todo
- `Ctrl + L` → Seleccionar línea
- `Ctrl + D` → Seleccionar siguiente coincidencia
- `Shift + Alt + →`, `Shift + Alt + ←` → Expandir/contraer selección
